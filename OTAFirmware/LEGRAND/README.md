Legrand firmware can be found here

https://developer.legrand.com/production-firmware-download/

A Legrand developer account is required: register or log in on the Legrand developer portal to reach the download page.

Manufacturer code 0x1021 (4129). Files are named like `1021-0013-003f45ff-NLV.zigbee` (manufacturer code, image type, file version, device reference).

Just download the file and store it in this folder, then restart the plugin: the firmware folders are read when the plugin starts.

Make sure that the folder has only the README.md file and Firmware files.
